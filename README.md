# Synthetic-Forecast_Verification
A set of forecast verification routines to evaluate synthetic hydrologic ensemble forecasts against actual forecasts. This repository is aligned with the data generated from two synthetic forecasting approaches that are located in the following GitHub repos:   
    
Synthetic Forecast version 1 [https://github.com/zpb4/Synthetic-Forecast-v1-FIRO-DISES](https://github.com/zpb4/Synthetic-Forecast-v1-FIRO-DISES)   
Synthetic Forecast version 2 [https://github.com/zpb4/Synthetic-Forecast-v2-FIRO-DISES](https://github.com/zpb4/Synthetic-Forecast-v2-FIRO-DISES)   

Data generated from these algorithms for any of the available hindcast locations can be systematically compared via common ensemble verification techniques with the scripts contained in this repository. Importantly, synthetic forecasts should be viewed in the context of their ability to emulate the actual forecast metrics, not in relation to ideal forecast performance. In other words, an ideal synthetic forecast mimics the metric performance of the actual forecasts (HEFS in this case). The scripts below target two primary periods for synthetic forecast verifications, the 'hindcast' period (HEFS, synthetic HEFS, and observations available) and the 'x-hindcast' period (synthetic HEFS and observations available, no HEFS). The x-hindcast period is primarily the pre-hindcast period, but may also include periods of observations after the HEFS hindcast period, which typically terminate in the year 2019. The x-hindcast verification compares the synthetic HEFS results to the hindcast period results where HEFS is available as a reference. In cases where the pre-hindcast period is much longer than the hindcast period, the verification calculation scripts will randomly resample (without replacement) x-hindcast periods in lengths equal to the hindcast period (usually ~ 30 years) to ensure similar sampling variability. In cases where the pre-hindcast period is equal to or shorter than the hindcast period, the scripts will resample (with replacement) from the x-hindcast period to the length of the hindcast period.    

*Important note*: If the x-hindcast period is significantly shorter than the hindcast period (limited pre-hindcast observations), as is often the case, the x-hindcast results will likely differ substantially from the hindcast results due to a lack of similarly sized extreme events. These discrepancies are expected and should not be interpreted as deficiencies in the synthetic forecasting algorithm. Typically, these much smaller subsets will exhibit higher skill (higher raw CRPS values, lower CRPS-SS values, and rank histogram values closer to the 1:1 line). (_a possible fix here is to only compare synthetic HEFS in these cases to HEFS in regimes that are $\leq$ the largest x-hindcast event_)   

To run these scripts, one must generate synthetic forecast samples from one or both of the referenced algorithms. R scripts in this repository extract data directly from R data structure (.rds) files generated by the main synthetic forecast script that are coded in R.  Generally speaking, synthetic forecast generations on the order of 10 samples are tractable for processing on a typical personal computing platform (e.g. PC or Mac). Larger samples will require a platform with sufficient RAM (i.e. HPC) to allow manipulation and plotting of the large data arrays. There are some scripts in the workflow that reduce larger samples to a smaller 10 sample chunks for visualization. The synthetic forecasting algorithm (version 2) has a number of modifiable parameter settings that must be matched in the verification and plotting scripts below to ensure the right data are being called for processing and visualization. The plotting scripts are written to output .png figure files to a directory of the user's choosing, and they are designed to produce a very thorough set of figures for detailed diagnosis.

## Workflow   
Note: Current date/time indices are setup to be compatible for all current hindcast sites that are available to be generated (ADO, LAM, NHG, YRS). These sites all have different lengths of available observations and HEFS; the date chosen are common across all of them.
### Required pre-run items in synthetic forecast scripts
As noted above, it is required to run the associated synthetic forecast algorithms to generate both HEFS and syn-HEFS forecasts to compare. To prepare data for visualization, you must also run the following scripts in the synthetic forecast repos:

-  ./src/slice_plot-ens.R - slices a 10-sample chunk from the full synthetic forecast dataset. You still need to run this, even if generating only 10 samples, to conform with the naming convention of the R verification script

### Verification metrics calculation
Note: Most scripts below call functions from the './src/ensemble_verification_functions.py' script
To calculate the verification statistics for specified subset of the data (e.g. 99th percentile), you must first run these scripts. For large sample synthetic forecasts (100 or more samples), these calculations require a lot of RAM and can be time-consuming if not implemented on an HPC resource:   

- ./src/calc_ecrps-rankhist_base.R - calculates CRPS, CRPS-SS, MSE, percent bias, and standard deviation statistics for the hindcast period
- ./src/calc_ecrps-rankhist_base_xhindcast.R - calculates CRPS, CRPS-SS, MSE, percent bias, and standard deviation statistics for the x-hindcast period

### Plotting
Plot ensemble visualizations of multiple lead times against a set of extreme events. Note: these scripts will not run if the './src/slice_plot-ens.R' from the synthetic forecast generation algorithm have not been run:
- ./src/plot_ensembles_ggplot.R - plots the HEFS ensembles and three samples of synthetic HEFS for multiple leads across a specified number of the Top-X events in the hindcast period; includes plots of the resampled HEFS sequences and scaling values for reference. _Note: currently the resampled HEFS and scaling functionality does not work with the '5fold' or '5fold-test' cal-val settings; fix in progress_
- ./src/plot_ensembles_xhindcast_ggplot.R - plots the HEFS ensembles and three samples of synthetic HEFS for multiple leads across a specified number of the Top-X events in the x-hindcast period; includes plots of the resampled HEFS sequences and scaling values for reference
- ./src/plot_ensembles-only_ggplot.R - this script is the same as './src/plot_ensembles_ggplot.R' but removes the HEFS resamples and scaling plots and will not throw an error if '5fold' or '5fold-test' cal-val setting is run.

- ./src/plot_verification_base-ggplot.R - plots raw CRPS, CRPS skill score, MSE, percent bias, and standard deviation metrics across lead times as well as the CRPS and CRPS-SS statistics for the top-10 declustered events in the hindcast period
